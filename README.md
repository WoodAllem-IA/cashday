# CashDay

App de cobrança de empréstimos para iPhone (app web instalável).

- Clientes, empréstimos com juros variável, parcelas ou só juros, multa diária por atraso.
- Tela "Hoje" com atrasados e vencimentos, botão para cobrar no WhatsApp.
- Os dados ficam guardados só no celular (use "Copiar backup" em Ajustes).

Abra pelo Safari no iPhone e toque em Compartilhar → Adicionar à Tela de Início.
